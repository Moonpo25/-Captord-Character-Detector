# Contributing to Captord

Captord is a privacy-first, **local-only** Android screen recorder. There is no
cloud upload, no analytics, and no remote backend. Contributions must preserve
that promise.

## Prerequisites

| Tool | Version | Notes |
|------|---------|-------|
| JDK | 17 | `compileOptions` and `kotlinOptions` are pinned to 17. |
| Android SDK | API 35 (compileSdk) | Installed via Android Studio or `sdkmanager`. |
| Min Android target | API 29 | Older devices are not supported. |
| Build tools | matches AGP 9.x | Pulled by Gradle if missing. |

`local.properties` is generated by Android Studio or you can write it manually:

```properties
sdk.dir=/absolute/path/to/Android/sdk
```

## First build

```bash
git clone https://github.com/Drenzzz/Captord.git
cd Captord
./gradlew :app:installDebug
```

The first build downloads dependencies and may take several minutes. Subsequent
builds are incremental.

## Development workflow

```bash
# Unit tests
./gradlew :app:testDebugUnitTest

# Lint
./gradlew :app:lintDebug

# Compose UI tests on a connected device or emulator
./gradlew :app:connectedDebugAndroidTest

# Debug build
./gradlew :app:assembleDebug

# Release build (requires signing env vars — see "Release signing" below)
./gradlew :app:assembleRelease
```

All commands must run from the repository root unless noted otherwise.

## Code style

- **Language:** Kotlin only. No Java sources.
- **UI:** Jetpack Compose + Material 3. Dynamic color primary on API 31+;
  fixed semantic colors for `REC` / `paused` / `stop` (see
  `CaptordSemanticColors`).
- **State:** ViewModel + StateFlow. No Riverpod, no Hilt.
- **Navigation:** Navigation Compose, single Activity.
- **Storage:** DataStore Preferences (not SharedPreferences).
- **Persistence pattern:** Recording output is written under
  `Movies/Captord/.pending` with a `.nomedia` marker, then renamed to its
  final name only after the engine / muxer finalizes successfully. Failed
  recordings must never appear in the gallery.
- **Recording semantics:**
  - Timer / state are driven by the foreground service via Flow/StateFlow,
    not by a UI-only periodic timer.
  - `startForeground()` is called **before** `getMediaProjection()` on API 34+.
  - The completion notification fires only after successful finalization.
  - Session safety: bounded partial wake lock is held only for an active
    session; released on stop / failure / service destroy.

## Commit messages

Conventional Commits with a scope:

```
type(scope): short imperative summary

Longer explanation, wrapped at ~72 chars. Reference REQ IDs or planning
docs sections where relevant.
```

Common scopes: `recorder`, `engine`, `ui`, `settings`, `service`, `gallery`,
`storage`, `overlay`, `audio`, `theme`, `infra`, `release`. Keep commits
atomic — one logical change per commit.

## Pull requests

- Use the PR template (auto-populated when you open a PR).
- Title format: `<type>(<scope>): <subject>` matching the planned commit.
- Reference any issue or planning doc: `Fixes #123`, `Refs REQ-024`,
  `Refs planning-docs-kotlin/02-architecture.md#adr-014`.
- Add or update tests for non-trivial behavior changes.
- CI must pass: `./gradlew :app:testDebugUnitTest` and
  `./gradlew :app:lintDebug`.

## Privacy rules

Contributions **must not** add:

- Network upload, telemetry, or analytics calls.
- Cloud backup, sync, or remote storage.
- Advertising or attribution SDKs.
- Permission requests outside the existing `AndroidManifest.xml` set
  (`RECORD_AUDIO`, `WAKE_LOCK`, `FOREGROUND_SERVICE*`, `POST_NOTIFICATIONS`,
  `READ_MEDIA_VIDEO`, `SYSTEM_ALERT_WINDOW`, `READ_EXTERNAL_STORAGE` capped
  at API 32).
- Hidden changes to system settings without an explicit, gated user toggle.

If a feature cannot be implemented within these constraints, it is out of
scope for Captord.

## Release signing (maintainers only)

Release builds read the signing config from environment variables. Set these
locally before running `assembleRelease` or pushing the release CI workflow:

| Variable | Purpose |
|----------|---------|
| `KEYSTORE_PATH` | Absolute path to the upload keystore. |
| `KEYSTORE_PASSWORD` | Keystore password. |
| `KEY_ALIAS` | Key alias inside the keystore. |
| `KEY_PASSWORD` | Key password. |

Never commit the keystore, its password, or its path to the repository.

## Reporting bugs

Open an issue using the **Bug report** template. Include:

- Device model and Android version.
- Captord version (visible in Settings).
- Steps to reproduce, expected behavior, actual behavior.
- If convenient: a logcat slice with the tags
  `MediaCodec:* AdvancedRecorder:* StandardRecorder:* ScreenRecorderService:*`.
